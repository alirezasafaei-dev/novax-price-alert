# اتوماسیون رشد نواکس بدون اسپم

این سند روش رشد خودکار و قابل دفاع برای `@novax_price_bot` و Mini App نواکس را توضیح می‌دهد. هدف، گرفتن کاربر از مسیرهای داوطلبانه و قابل اندازه‌گیری است؛ نه پیام خصوصی انبوه، اسکرپ ممبر، اددر یا دور زدن محدودیت‌های تلگرام.

## اصل اصلی

نواکس باید مثل یک ابزار کاربردی معرفی شود، نه مثل یک کانال تبلیغاتی.

پیام اصلی:

> قیمت دلار، تتر، طلا یا کریپتو را تنظیم کن؛ وقتی بازار به عدد دلخواهت رسید، بات در تلگرام بهت هشدار می‌دهد.

## مسیر خودکار پیشنهادی

```text
کانال/پیج/گروه مرتبط
  -> لینک کمپینی اختصاصی
  -> /start source در بات
  -> ثبت campaign attribution در D1
  -> کاربر اولین هشدار را می‌سازد
  -> اگر با لینک دعوت آمده باشد، referral معتبر می‌شود
  -> دعوت‌کننده بعد از ۳ دعوت موفق، ۷ روز Pro می‌گیرد
  -> ادمین با /growth منابع پربازده را می‌بیند
```

## قابلیت‌هایی که در پروژه وجود دارد

- Campaign attribution با `/start <source>`
- Referral link با الگوی `/start ref_<telegram_user_id>`
- پاداش ریفرال: هر ۳ دعوت موفق = ۷ روز Pro رایگان
- Daily marketing post برای کانال رسمی
- گزارش رشد با دستور `/growth`

## تنظیمات لازم در Worker

```env
BOT_USERNAME=novax_price_bot
MARKETING_POSTING_ENABLED=true
MARKETING_CHANNEL_ID=-100xxxxxxxxxx
MARKETING_POST_HOUR_TEHRAN=10
```

بعد از تنظیم متغیرها، migration رشد را روی D1 اعمال کن:

```bash
cd deploy/cloudflare-worker
npx wrangler d1 migrations apply novax-product --remote
```

سپس بات و webhook را ست کن:

```bash
curl -X POST "https://<worker-domain>/setup-bot" \
  -H "X-Setup-Secret: $SETUP_SECRET"
```

## قانون ضد اسپم

این روش‌ها انجام نشود:

- پیام خصوصی به کاربران ناشناس
- استخراج ممبر از گروه‌ها یا کانال‌ها
- اضافه‌کردن اجباری کاربر به گروه/کانال
- استفاده از چندین اکانت برای ارسال انبوه
- ارسال تبلیغ در گروه‌ها بدون اجازه ادمین

## برنامه اجرایی ۷ روزه

### روز ۱

- تنظیم `BOT_USERNAME`
- فعال‌کردن daily marketing post
- ساخت کانال رسمی نواکس
- ست‌کردن Mini App در BotFather

### روز ۲

- آماده‌کردن ۵ لینک کمپینی
- انتشار اولین پست در کانال رسمی
- گرفتن آمار اولیه با `/growth`

### روز ۳

- تبلیغ تستی در ۲ کانال مرتبط با کریپتو یا دلار
- برای هر کانال لینک جدا استفاده شود

### روز ۴

- بررسی `/growth`
- حذف منبع کم‌بازده
- افزایش بودجه یا تمرکز روی منبع پربازده

### روز ۵

- اجرای کمپین ریفرال با پیام واضح:
  «۳ دوست دعوت کن، ۷ روز Pro رایگان بگیر»

### روز ۶

- انتشار ویدئوی کوتاه از ساخت هشدار در Mini App
- استفاده از لینک کمپینی مخصوص ویدئو

### روز ۷

- بررسی conversion واقعی: چند نفر فقط وارد شدند و چند نفر هشدار ساختند
- ادامه فقط با منابعی که هشدار فعال ساخته‌اند، نه صرفاً ورودی خام

## شاخص‌های مهم

- تعداد start از هر source
- تعداد کاربرانی که هشدار فعال ساخته‌اند
- تعداد referral معتبر
- تعداد پاداش Pro داده‌شده
- نسبت هشدار فعال به start

شاخص اصلی رشد نواکس فقط تعداد ممبر نیست؛ تعداد کاربرانی است که واقعاً هشدار قیمت ساخته‌اند.
