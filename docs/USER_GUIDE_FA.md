# راهنمای کاربر نواکس

نواکس یک ربات تلگرام و مینی‌اپ برای مشاهده قیمت و ساخت هشدار قیمت است.

## امکانات فعلی

- مشاهده قیمت کریپتو با واحد USDT و قیمت بازار ایران با واحد تومان.
- ساخت، مشاهده، توقف/ادامه و حذف هشدارها از ربات یا مینی‌اپ.
- پلن رایگان با محدودیت تعداد هشدار و پلن Pro پولی با ظرفیت/فاصله بررسی بهتر.
- ثبت دستی مرجع پرداخت برای بررسی اپراتور.

## نکته‌های مهم

- نواکس مشاوره مالی نیست و صحت/تازگی قیمت‌ها تضمین نمی‌شود.
- اگر منبع قیمت قطع یا کهنه باشد، هشدار نباید بر اساس آن فعال شود.
- دستور `/deleteall` فعلاً وجود ندارد؛ برای حذف کامل داده‌ها با اپراتور تماس بگیرید.
