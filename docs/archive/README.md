# آرشیو مستندات

این پوشه شامل اسناد تاریخی و superseded است و منبع حقیقت پروژه نیست.

- `legacy-deployment/`: راهنماها و گزارش‌های قدیمی VPS، Render، Neon و KV
- `reports/`: گزارش‌های مقطعی، roadmapها و خلاصه‌های تکمیل
- `guides/`: راهنماهای کوتاه قدیمی
- `root/`: فایل‌های قدیمی که قبلاً در ریشهٔ repository بودند
- سایر فایل‌ها: قراردادها و طرح‌های phase-specific بازنشسته

مقادیر حساس باید پیش از آرشیو حذف شوند. آرشیو کردن، افشای secret در تاریخچهٔ
git را برطرف نمی‌کند.
